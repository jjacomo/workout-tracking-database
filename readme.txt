Database Project - Sports Activity Monitoring

Database setup:

Start MariaDB/MySQL and create the complete schema by running:

mysql -u root -p < database.sql

The script creates the `allenamenti_db` database with all tables.

Run popolamento.sql (generated by AI) to populate the database; the data reflects the volumes described in the report.

------------------------------------------------------

Starting the application

From the main directory:

./gradlew run

At startup, you will be prompted for the MariaDB/MySQL username and password.

The SQL queries used by the application are collected mainly in:
app/src/main/java/db_lab/data/Queries.java

The application implements the main operations defined in the report.
